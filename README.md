 # 🇪🇸 Analizador de Ofertas - Madrid
**De Cajamarca a Madrid con Python**

Mi primera IA que calcula si una oferta de trabajo en España te permite vivir solo.

### ¿Qué hace?
Convierte sueldo bruto anual (ej: 52.000€) a neto mensual en 14 pagas y resta gastos reales de Madrid:
- 1150€ Alquiler
- 400€ Comida
- 150€ Transporte/Otros
= Te dice cuanto te queda LIBRE

### Resultados reales
- 28.000€/año -> -180€ ❌ No alcanza ni para vivir solo
- 45.000€/año Telefónica -> +743€ 👍 Justo
- 52.000€/año Cabify -> +1.123€ ✅ Excelente, ahorras

### Tecnología
Python - Funciones, condicionales, cálculos
